Возможности

Всё, что нужно, — в одном приложении

Не «ещё один блокнот с подсветкой». Настоящий редактор: вкладки, диагностика, автодополнение, запуск кода, ИИ, плагины и экспорт проекта одним архивом.

Подсветка 23 языков

Собственный токенизатор: ключевые слова, типы, строки, числа, комментарии, функции и макросы. Радужные скобки, мини-карта, номера строк, перенос длинных строк.

без сторонних библиотек

Запуск любого языка

Одна кнопка ▶ понимает, что за файл перед ней. Есть компилятор на телефоне — запустит локально. Нет — отправит в облако и вернёт только результат, без служебных логов.

Wandbox · Rust Playground

ИИ-помощник без ключа

Открывается и сразу работает: бесплатные провайдеры, ключ не нужен. Просит объяснить код, найти ошибку, переписать функцию. Если один сервер молчит — переключится на второй.

Pollinations · LLM7

Вопросы

Коротко о главном

Браузер скачал файл как .zip — это нормально?

Да. APK устроен как ZIP-контейнер, поэтому некоторые браузеры и файловые менеджеры так его подписывают. Переименуйте файл в .apk — содержимое уже правильное и подписанное.

Нужен ли интернет?

Редактор, подсветка, автодополнение, плагины, темы и экспорт проекта работают полностью офлайн. Интернет нужен только для запуска кода в облаке (если на телефоне нет компилятора) и для ИИ-помощника.

Почему APK только для arm64?

Это архитектура практически всех телефонов последних лет. Сборка под неё даёт меньший размер и меньше проблем с производительностью. Если понадобится x86 — сообщите.

Откуда берётся запуск без установки компиляторов?

Для 15+ языков используется бесплатный публичный сервис Wandbox, для Rust — Rust Playground. Код уходит, ответ приходит чистым результатом: только то, что напечатала ваша программа, плюс отдельный блок ошибок.

Это копия VS Code?

Нет. Ferrum IDE написан с нуля на Rust (egui + eframe) и не использует код Visual Studio Code, Code-OSS или Monaco. Совпадает только сам подход к удобству: автодополнение, палитра команд, плагины с исходным кодом.

Где мои файлы?

В папке приложения на телефоне. Есть проводник, создание и удаление файлов, автосохранение — чтобы работа не потерялась, если Android закроет приложение.
